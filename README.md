# Dheepak Karan — Research & Engineering

A local-first academic portfolio built with React, TypeScript and vinext.

## Pages

- `/` — profile, coursework, selected work, experience and skills
- `/work` — complete engineering project archive
- `/blog` — engineering notes
- `/resume.pdf` — downloadable résumé

## Local development

Requires Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Validation

```bash
npm run build
npm test
```

The portfolio is static and does not use authentication, a database, analytics
or a contact-form backend. Hosting is intentionally not part of the local
workflow.
